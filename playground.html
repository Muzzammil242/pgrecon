pgrecon playgroundv0.5.0
the full CLI, in your browser

This page runs the real pgrecon - the same package pip install pgrecon gives you, not a demo build - inside a Python runtime compiled to WebAssembly. There is no server behind this page: the runtime and the package download once, then everything, including any dump you open, stays in this tab. Close it and it is gone.

Back to pgrecon GitHub PyPI

1. Boot the runtime

Downloads about 15 MB once: the Python runtime, then pgrecon==0.5.0 and its three dependencies straight from PyPI.

2. Load an estate

Use the extraction dump from a live Oracle XE 21c that ships in the repository, or open one of your own - the folder of spool files the pgrecon script extraction produces. Loading deep-parses every stored PL/SQL unit with a full grammar; under WebAssembly that takes a minute or two and the tab will feel frozen while it works. The installed CLI does the same in seconds.

or open your own:

Select all files inside your dump folder. They are read into the in-tab filesystem only; nothing is uploaded, and you can verify that with the network panel of your browser's developer tools.

3. Run pgrecon

The session transcript appears here.
schema_pg.sql - the emitted PostgreSQL DDL 





schema_residue.txt - everything declined, by name, with the reason
