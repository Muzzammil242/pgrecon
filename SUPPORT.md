# Support

## Community support

Questions, bug reports, and rule requests are welcome as GitHub
issues. Every rule ships with fixture tests, so a good bug report
with a snippet of the DDL or PL/SQL that misbehaved is usually fixed
quickly. Security reports go through the private channel described
in SECURITY.md, never public issues.

## Commercial support

The maintainer offers commercial Oracle-to-PostgreSQL work through
